# <img src="OpenRGBHardwareSyncPlugin.png" width="48" height="48" style="vertical-align: middle;"/> OpenRGB Hardware Sync Plugin

[![pipeline status](https://gitlab.com/OpenRGBDevelopers/OpenRGBHardwareSyncPlugin/badges/master/pipeline.svg)](https://gitlab.com/OpenRGBDevelopers/OpenRGBHardwareSyncPlugin/-/commits/master)

This is a plugin for [OpenRGB](https://gitlab.com/CalcProgrammer1/OpenRGB) that allows you sync your ARGB devices with hardware measures (CPU temperature, RAM usage, fans speed, etc...)

## Features

* View your hardware statistics on your RGB devices
* Supports multiple measurements at once
* View as either a single color or as a line graph
* Save measurements to OpenRGB profiles

## Website

* Check out our website at [openrgb.org/plugin_hardware_sync](https://openrgb.org/plugin_hardware_sync.html)
## Supported Devices

* Supports any OpenRGB device that has Direct mode

## Installation

  * Pre-built binaries are available for the following platforms:
    * Windows
    * Linux (.so, .deb, and .rpm)
  * Released versions are available to download on [OpenRGB.org](https://openrgb.org/plugin_hardware_sync.html).
  * Experimental (aka Pipeline) versions are available to download on [OpenRGB.org](https://openrgb.org/plugin_hardware_sync.html#pl).
  * The pre-built .so binaries are intended to be used with the OpenRGB AppImage builds and may not be compatible with OpenRGB installed from other sources.
  * Arch users can also install from the AUR for the [release](https://aur.archlinux.org/packages/openrgb-plugin-hardware-sync/) or [pipeline](https://aur.archlinux.org/packages/openrgb-plugin-hardware-sync-git/) version.
